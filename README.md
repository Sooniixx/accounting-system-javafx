## 📝 Опис застосунку та Бізнес-логіка

Система розроблена для автоматизації рутинних завдань бухгалтерії та відділу кадрів. 

**Ключове бізнес-правило (Аналітика):** Залишок оплачуваної відпустки співробітника обчислюється динамічно на рівні БД як сума базових та перенесених днів, мінус фактично використані дні, зафіксовані в таблиці відпусток.

## 🏗 Архітектура MVC

Проєкт чітко розділений на шари згідно з патерном MVC:

| Шар | Що містить | Пакет |
| :--- | :--- | :--- |
| **Model** | Класи предметної області: `Employee`, `Department`, `Vacation` | `model/` |
| **View** | JavaFX інтерфейс (UI) | `view/` |
| **Controller** | Обробка подій UI, валідація, взаємодія з Service | `controller/` |
| **Service (DAO)** | Доступ до БД через JDBC, бізнес-логіка | `service/` |

---

## 🗄 Схема бази даних

БД складається з 3 пов'язаних таблиць, що відповідають 3-й нормальній формі (3NF).
Довідник `departments` унеможливлює присвоєння працівнику неіснуючого відділу. Таблиця `vacations` містить історію відпусток.

* `employees` (id [PK], full_name, department_id [FK], ...)
* `departments` (id [PK], name)
* `vacations` (id [PK], employee_id [FK], start_date, end_date)
